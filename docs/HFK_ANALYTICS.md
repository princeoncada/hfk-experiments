## How to Fill This In

After 48 hours, go to Facebook Page Insights → Posts.
For each post, record:
- Reach (how many people saw it)
- Saves (click the post metrics — saves are listed separately)
- Shares
- Comments (total + how many say "SEND")

Paste in the format below, then open a Claude Code session and say:
"Analytics review — read HFK_ANALYTICS.md and update the experiment log."
