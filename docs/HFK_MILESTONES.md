# HFK Milestones

Version: 1.0 | Created: 2026-05-26 | See docs/HFK_CHANGELOG.md

Milestones are performance gates. Hitting one unlocks a workflow change —
a new variable, a design upgrade, or a distribution shift. Nothing in this
system changes without a milestone being hit first.

Claude Code checks these during Strategy Sessions (Type C) and reports
progress whenever analytics are logged.

---

## Active Milestones

### M1 — First Signal
**Goal:** Any single experiment hits strong signal.
**Threshold:** 20+ saves OR 10+ shares OR 5+ SEND comments on one post.
**Status:** `locked` — 0 experiments posted
**Unlocks:**
- Apply Level 2 design upgrades to all future worksheets (see docs/HFK_FUTURE.md → Design)
- Confirm the content-first strategy is working

---

### M2 — Baseline Established
**Goal:** 5 experiments completed with full analytics logged.
**Threshold:** 5 rows in Tested Combinations with non-empty analytics.
**Status:** `locked` — 0/5 complete
**Unlocks:**
- Rebalance priority queue based on real data (not assumptions)
- Introduce multipage format as Style E in the variable matrix
- Begin pattern analysis across style, content, hook, and CTA dimensions

---

### M3 — First Winner Confirmed
**Goal:** One combination achieves strong signal across 3+ separate posts.
**Threshold:** Same Style+Content combo hits strong signal in 3 different experiments.
**Status:** `locked` — no winners yet
**Unlocks:**
- Shift from exploration mode to exploitation mode
- Double down on winner combination — 3x per week instead of 1x
- Begin designing themed worksheet bundles around the winning format
- Reduce experiment frequency from daily to 3x per week

---

### M4 — Audience Signal
**Goal:** Meaningful DM/SEND volume reached.
**Threshold:** 50+ total SEND comments across all posts OR 100+ saves on a single post.
**Status:** `locked` — 0 SEND comments logged
**Unlocks:**
- Evaluate DM automation tools (ManyChat or similar)
- Begin packaging PDFs as a free resource library
- Consider building an email/Messenger list from SEND responders

---

### M5 — Content Authority
**Goal:** HFK is a recognized source in the Filipino homeschool Facebook community.
**Threshold:** 10+ completed experiments + clear winner + 500+ page followers gained organically.
**Status:** `locked` — pre-launch
**Unlocks:**
- Launch Sprint 2 with advanced variable matrix (mascot, DepEd badge, multipage, seasonal themes)
- Evaluate paid content and Gumroad/Etsy distribution
- Consider Instagram and Pinterest expansion
